
# Mi Primer Proyecto Git

Proyecto de práctica desarrollado para aprender los fundamentos
de Git y GitHub en la asignatura Desarrollo Web de ESINTEC.

## Descripción

Este proyecto consiste en una página web sencilla que permite
mostrar un mensaje de bienvenida al presionar un botón.

## Tecnologías utilizadas

- HTML5
- JavaScript
- Git
- GitHub
- Visual Studio Code

## Funcionalidades

- Mostrar un título de bienvenida.
- Presentar información del proyecto.
- Ejecutar una alerta mediante JavaScript.
- Registrar y publicar versiones con Git y GitHub.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Localizar el archivo `index.html`.
4. Abrir el archivo en un navegador web.
5. Presionar el botón "Haz clic aquí".

## Objetivo académico

Comprender el funcionamiento del control de versiones,
los commits y la publicación de proyectos en GitHub.
